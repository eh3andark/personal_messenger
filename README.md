# 💬 چت امن

چت امن یه پیام‌رسان فارسی برای نصب روی هاست cPanelـه. برای چت اصلی به MySQL، ربات یا سرویس جداگانه نیاز نداره. نسخهٔ فعلی پروژه **۱.۰** است.

## ⬇️ دانلود آخرین نسخه

1. برو به [صفحهٔ آخرین نسخه در GitHub](https://github.com/eh3andark/personal_messenger/releases/latest).
2. بخش **Assets** رو باز کن و **`hamrah-messenger-cpanel.zip`** رو دانلود کن.
3. فایل **Source code (zip)** رو به‌جای بستهٔ نصب نگیر؛ اون کد منبع پروژه‌ست.

## 🚀 نصب روی cPanel

1. هاستت باید **PHP 7.4 یا جدیدتر**، افزونه‌های `openssl`، `mbstring` و `fileinfo` و **HTTPS** داشته باشه. این بسته برای Apache یا LiteSpeed و قواعد `.htaccess` آماده شده.
2. توی **cPanel → File Manager** یه پوشهٔ خالی مثل `public_html/chat` بساز. ZIP رو اونجا آپلود و **Extract** کن. فایل‌های `index.php` و `setup.php` باید مستقیم داخل همین پوشه باشن. بعدش خود ZIP رو از پوشهٔ سایت پاک کن.
3. آدرس `https://example.com/chat/setup.php` رو باز کن (`example.com` فقط یه مثال است؛ آدرس واقعی سایتت رو جایگزین کن). بعد توی File Manager نمایش **فایل‌های مخفی** رو فعال کن، فایل `data/.setup_token.php` رو باز کن و **فقط کد بعد از `return`** رو در فرم نصب وارد کن. آیدی و رمز قوی مدیر رو هم خودت انتخاب کن؛ رمز پیش‌فرضی وجود نداره. کد نصب رو برای دیگران نفرست.
4. وارد برنامه شو و از پنل مدیریت، حساب کاربران رو بساز. قبل از استفادهٔ واقعی، مطمئن شو فایل‌های داخل `data/` و `core/` از مرورگر باز نمی‌شن و خطای **403 یا 404** می‌دن. اگر محتوای فایل خصوصی نمایش داده شد، نصب رو متوقف کن.

## 🔐 شفاف‌سازی مهم دربارهٔ حریم پیام‌ها

> **آیا مدیر هاست می‌تونه پیام‌ها رو بخونه؟ بله، اگر به سرور و فایل‌ها دسترسی داشته باشه.** پیام‌های جدید موقع ذخیره‌شدن رمز می‌شن، اما کلید رمزگشایی روی همون سروره و PHP برای نمایش پیام ازش استفاده می‌کنه. کسی که به **داده و کلید** دسترسی داشته باشه، یا بتونه کد PHP سرور رو تغییر بده، می‌تونه محتوای پیام‌ها رو بخونه. پس چت امن **رمزنگاری سرتاسری (E2EE) نیست**. HTTPS از ارتباط تا سرور محافظت می‌کنه، نه از پیام‌ها در برابر خودِ مدیر هاست.

## ⚠️ موقع ارتقا حواست باشه

ZIP بالا برای **نصب تازه** است. اگر برنامه رو از قبل نصب کردی، اول از **کل برنامه و کل پوشهٔ `data/`** بکاپ بگیر. ZIP تازه رو روی `data/` فعلی Extract نکن؛ پیام‌ها و کلید رمزنگاری نصب تو اون پوشه‌اند.
