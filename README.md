# چت امن | Chat Amn 🛡️

**چت امن 4.2.0:** یک پیام‌رسان فارسی و راست‌به‌چپ که خیلی راحت روی هاست‌های اشتراکی cPanel نصب می‌شه. 
بدون نیاز به دیتابیس MySQL، بدون نیاز به سرویس‌های دائمی و بدون وابستگی به سرورهای خارجی برای چت کردن!

## 📥 دانلود و نصب برنامه اصلی (روی هاست)

برای نصب نسخه وب (برنامه اصلی) روی هاست cPanel خود، به بخش [Releases](https://github.com/eh3andark/personal_messenger/releases) در گیت‌هاب برو و از قسمت **Assets** فایل **`hamrah-messenger-cpanel.zip`** رو دانلود کن. 

> ⚠️ **توجه:** فایلی که گیت‌هاب خودش به اسم «Source code (zip)» می‌سازه، فقط کدهای خام است و برای نصب روی هاست مناسب نیست. حتماً فایل ZIP رو از بخش Assets دانلود کن.

## ✨ چه کارهایی می‌کنه؟

- 💬 **چت و رسانه:** ارسال پیام متنی، عکس، ویدیو، ویس و فایل. جستجو در تاریخچه، پیام‌های ذخیره‌شده و فضای شخصی برای فایل‌ها.
- 📊 **آمار برای مدیر:** در پنل مدیریت می‌تونی آخرین ورود، وضعیت آنلاین بودن و روزهای عدم فعالیت هر کاربر رو ببینی تا حساب‌های بی‌استفاده رو پیدا کنی.
- 👥 **گروه و کانال:** ساخت گروه خصوصی با لینک دعوت، جستجوی گروه‌های عمومی، و کانال اطلاعیه برای ارسال پیام توسط ادمین.
- 📱 **طراحی موبایل و فارسی:** محیط کاملاً راست‌به‌چپ (RTL)، قابلیت نصب به‌عنوان اپلیکیشن (PWA) و ۱۰ فونت فارسی زیبا که نیازی به اینترنت خارجی ندارن.
- 🗑️ **مدیریت فضا:** وقتی فضای هاست به ۸۰٪ برسه، ارسال رسانه (عکس/ویدیو) متوقف می‌شه ولی چت متنی ادامه داره. کاربر می‌تونه پیام‌های خودش رو پاک کنه.
- 🛠️ **ابزارهای جانبی (اختیاری):** پیش‌نمایش پست‌های تلگرام، جستجو در ویکی‌پدیا، و نمایش نرخ ارز و طلا (از سایت TGJU). این ابزارها برای چت اصلی ضروری نیستن.

## 🚀 راهنمای نصب قدم‌به‌قدم (روی cPanel)

1. **دانلود و آپلود:** فایل `hamrah-messenger-cpanel.zip` رو از Releases دانلود کن. در cPanel به **File Manager** برو، یک پوشه خالی در `public_html` بساز، فایل ZIP رو آپلود و اونجا **Extract** (خارج) کن. (فایل‌های `index.php` و `setup.php` باید مستقیم در ریشه پوشه باشن).
2. **ساخت توکن:** آدرس `https://YOUR-DOMAIN/setup.php` رو یک‌بار در مرورگر باز کن تا یک فایل مخفی به اسم `data/.setup_token.php` ساخته بشه. با File Manager محتوای این فایل رو باز کن و کد داخلش رو کپی کن.
3. **ثبت‌نام مدیر:** در صفحه نصب، اون کد (توکن) رو وارد کن و نام کاربری و رمز عبور مدیر اصلی رو تنظیم کن. (هیچ رمز پیش‌فرضی وجود نداره). بعد از این کار، نصب برای همیشه قفل می‌شه.
4. **تست:** با حساب مدیر وارد شو، یک حساب آزمایشی بساز و یک پیام و عکس بفرست تا مطمئن شی همه چیز درست کار می‌کنه.
5. **امنیت:** حتماً چک کن که اگر آدرس `https://YOUR-DOMAIN/data/users.json` رو در مرورگر باز می‌کنی، خطای 403 یا 404 بده و محتوای فایل نشون داده نشه.

> 📖 راهنمای کامل‌تر و تصویری در فایل [README-FA.md](README-FA.md) قرار داره.

## 🔄 آپدیت کردن (بدون پاک شدن داده‌ها)

اگر نسخه جدیدی اومد و خواستی آپدیت کنی:
1. از **کل کدها** و **پوشه `data/`** (به همراه فایل‌های مخفی) یک بکاپ کامل بگیر.
2. فایل ZIP نسخه جدید رو دانلود کن.
3. فقط فایل‌های کد و دارایی‌ها (assets) رو جایگزین کن. **به هیچ وجه پوشه `data/` رو پاک نکن یا جایگزین نکن!** اطلاعات کاربران، پیام‌ها و کلیدهای رمزنگاری همگی اونجا هستن.

## 🔒 امنیت و حریم خصوصی (مهم)

- **متن‌ها رمزنگاری می‌شن، اما E2EE نیست:** پیام‌های جدید در سرور شما رمزنگاری می‌شن، اما اسکریپت PHP برای نمایش، اون‌ها رو باز می‌کنه. یعنی مدیر هاست (یا کسی که به کلیدها دسترسی داره) می‌تونه پیام‌ها رو بخونه.
- **محافظت از پوشه data:** فایل `.htaccess` جلوی دسترسی مستقیم به پوشه `data/` و `core/` رو می‌گیره. اگر از Nginx استفاده می‌کنی، باید تنظیمات معادلش رو خودت اعمال کنی.
- **گزارش باگ:** لطفاً باگ‌های امنیتی رو به صورت خصوصی از طریق [SECURITY.md](SECURITY.md) اطلاع بده و هیچ‌وقت توکن‌ها، رمزها یا پیام‌های واقعی رو در Issues عمومی نذار.

## 🧩 اکستنشن مرورگر کروم (نسخه 1.1)

علاوه بر نسخه وب، یک اکستنشن (افزونه) برای مرورگر گوگل کروم نیز منتشر شده است.
برای نصب این اکستنشن:
1. فایل ZIP مربوط به اکستنشن را از بخش [Releases](https://github.com/eh3andark/personal_messenger/releases) دانلود کنید.
2. فایل ZIP را از حالت فشرده خارج کنید.
3. در مرورگر کروم به آدرس `chrome://extensions` بروید.
4. حالت **Developer mode** (حالت توسعه‌دهنده) را در گوشه بالای صفحه فعال کنید.
5. روی دکمه **Load unpacked** کلیک کنید و پوشه‌ای که از حالت فشرده خارج کرده‌اید را انتخاب کنید.
