# چت امن — راهنمای نصب و استفاده (نسخهٔ ۴.۲)

**صاحب پروژه و منتشرکننده: [eh3andark](https://github.com/eh3andark)** · [مخزن رسمی](https://github.com/eh3andark/personal_messenger) · [دریافت بستهٔ نصب از Releases](https://github.com/eh3andark/personal_messenger/releases) (بعد از انتشار اولین Release) · [مجوز MIT](LICENSE) · [اعتبار و مجوزهای مستقل](NOTICE.md)

سلام! «چت امن» یک پیام‌رسان فارسی و راست‌چین برای **هاست معمولی cPanel با Apache/LiteSpeed** است. پیام‌ها و فایل‌های تازه روی سرور رمز می‌شوند؛ برای گفتگوی اصلی و فضای شخصی **MySQL، VPS، ربات، CDN، فونت اینترنتی یا سرویس خارجی نمی‌خواهد**. طراحی‌اش از راحتی تلگرام الهام گرفته، ولی **محصول رسمی تلگرام یا جایگزین هم‌قابلیت آن نیست** و **رمزنگاری سرتاسری (E2EE) هم نیست**.

## قبل از نصب، این‌ها را چک کن

- PHP **۷.۴ یا جدیدتر**؛ ۸.۱ به بالا بهتر است. افزونه‌های `json`، `openssl`، `mbstring` و `fileinfo` لازم‌اند. برای خواندن اختیاری کانال عمومی تلگرام و ابزارهای وب، `dom` و `curl` هم لازم‌اند. فضای کافی و اجازهٔ نوشتن در `data/` داشته باش.
- **HTTPS و قواعد `.htaccess` فعال** باشند. HTTPS برای رمز عبور و محتوایی که در راه منتقل می‌شود لازم است؛ میکروفون/بعضی قابلیت‌های وب‌اپ هم به آن نیاز دارند. اگر Nginx داری، قبل از استفادهٔ واقعی قواعد منع دسترسی به `data/`، `core/`، فایل‌های مخفی و نسخه‌های پشتیبان را خودت معادل‌سازی کن؛ ZIP مخصوص Apache/LiteSpeed است.
- کلید اصلی و فایل‌های `data/` فقط روی هاست بمانند. بکاپ امنِ خارج از پوشهٔ عمومی بگیر. **اگر کلید اصلی گم شود، دادهٔ رمز‌شده را نمی‌شود برگرداند.**

## دانلود از GitHub: سورس با ZIP نصب چه فرقی دارد؟

اگر صاحب مخزن یک **Release** منتشر کرده، در [مخزن رسمی → Releases](https://github.com/eh3andark/personal_messenger/releases) به **نسخهٔ مورد نظر → Assets** برو و **`hamrah-messenger-cpanel.zip`** را بگیر. این مسیر ساده‌ترین راه نصب روی هاست است. اگر Releases هنوز خالی است، فایل نصب هنوز آنجا قرار نگرفته؛ خالی‌بودن صفحه را با خطای نصب اشتباه نگیر. دکمهٔ **Code → Download ZIP** و لینک خودکار **Source code (zip)** در Release، *کد منبع مخزن* را می‌دهند؛ خودشان «ZIP آمادهٔ نصب cPanel» نیستند. هیچ‌کدام کد نصب یا رمز آماده ندارند.

اگر فقط سورس در دسترس است، **Code → Download ZIP** را بزن و روی رایانه Extract کن. وارد پوشهٔ بازشدهٔ مخزن شو (برای این مخزن معمولاً `personal_messenger-main` نام دارد). اگر Python 3 داری، در همان پوشه این فرمان را اجرا کن:

```bash
python3 scripts/build_cpanel_zip.py
# در ویندوز، در صورت نصب Python Launcher: py -3 scripts/build_cpanel_zip.py
```

این اسکریپت فقط از کتابخانهٔ استاندارد Python استفاده می‌کند و **در پوشهٔ بالادستیِ سورس** فایل `hamrah-messenger-cpanel.zip` را می‌سازد. سپس همان ZIP نصب را طبق بخش بعد روی cPanel آپلود کن. بستهٔ سورس را بدون جداکردن فایل‌های توسعه (`tests/`، `.github/` و `scripts/`) مستقیماً داخل پوشهٔ عمومی هاست Extract نکن؛ و ZIP سورس را جایگزین `data/` یک نصب موجود نکن. اگر Python نداری، از منتشرکننده بخواه فایل ZIP نصبِ Release را بگذارد؛ این بسته را با فایل **Source code (zip)** اشتباه نگیر.

**کد نصب فقط روی هاستِ همان شخص ساخته می‌شود:** بعد از آپلود فایل‌های نصب، بازکردن `setup.php` یک مقدار تصادفیِ یک‌بارمصرف در `data/.setup_token.php` همان هاست می‌سازد. کاربر آن را از File Manager خودش می‌خواند. این کد در GitHub/ZIP نیست، کلید رمزنگاری اصلی نیست و نیازی به گرفتن آن از سازندهٔ پروژه ندارد. جزئیات در قدم ۳ بخش بعد آمده است.

## نصب تازه روی cPanel، قدم‌به‌قدم

1. فایل **`hamrah-messenger-cpanel.zip`** را در پوشهٔ جداگانه‌ای مثل `public_html/chat` آپلود و Extract کن. `index.php`، `setup.php`، `.htaccess`، `assets/`، `core/` و `data/` باید همان‌جا کنار هم باشند. ZIP آپلودشده را بعد از استخراج از پوشهٔ عمومی پاک کن. در File Manager، نمایش **Hidden Files** را روشن کن.
2. HTTPS و نسخه/افزونه‌های PHP را فعال کن. در مرورگر `/core/bootstrap.php` و `/data/.htaccess` را باز کن؛ باید **403 یا 404** بگیری، نه محتوای فایل. بعد از نصب، برای `/data/users.json`، `/data/user_activity.json` و `/data/.master_secret.php` هم همین را بررسی کن. اگر فایل خصوصی دانلود شد، **قبل از هر پیام واقعی نصب را متوقف کن**. از پنل مدیریت هم آزمون HTTP فایل‌های محافظت‌شده در دسترس است.
3. به `https://YOUR-DOMAIN/chat/setup.php` برو. برنامه یک توکن یک‌بارمصرف تصادفی در `data/.setup_token.php` می‌سازد. آن را فقط از **cPanel → File Manager** بردار و در فرم نصب وارد کن؛ آیدی مدیر و رمز قوی خودت را تعیین کن. **هیچ رمز، حساب نمونه یا کد نصب آماده‌ای در بسته/صفحهٔ ورود نیست.** بعد از ساخت مدیر، توکن پاک می‌شود و صفحهٔ نصب 404 می‌دهد.
4. وارد شو؛ از پنل مدیریت برای هر نفر حساب، رمز و سهمیه بساز. کاربران عادی فهرست تمام افراد را نمی‌بینند و مخاطب را با **آیدی دقیق** پیدا می‌کنند. برای بکاپ، تمام `data/`، کلید مخفی، فایل‌ها و زیرپوشه‌های مخفی آن را با هم و در جای محافظت‌شده کپی کن.

> **ارتقا داری؟** ZIP «نصب تازه» را روی `data/` نصب فعال Extract نکن. اول از کد **و کل `data/`** بکاپ و یک کپی آزمایشی بساز؛ فقط فایل‌های برنامه/قواعد امنیتی را جایگزین کن، نه داده و کلید را. نام پیش‌فرض قدیمی برنامه در نمایش به «چت امن» تبدیل می‌شود؛ نام دلخواهی که مدیر تنظیم کرده دست‌نخورده می‌ماند. رسانه‌های قدیمیِ ذخیره‌شده بدون رمز **خودکار** رمز نمی‌شوند. روی کپی آزمایشی ورود، گفتگوی قدیمی و پیوست‌ها را امتحان کن.

## امکاناتی که واقعاً کار می‌کند

- **حساب/حریم خصوصی:** مدیر کاربر تعریف یا حذف می‌کند، دسترسی/سهمیه می‌دهد، رمز یا داده را ریست می‌کند. آیدی تکراری با خطای روشن رد می‌شود. بعد از حذف امنِ حساب، همان آیدی دوباره قابل ساخت است ولی Saved Messages، Drive، نشست‌ها و رسانهٔ صاحب قبلی به نفر تازه منتقل نمی‌شود؛ فرستندهٔ قدیمی در گروه‌ها بی‌نام و فایل مشترکِ باقی‌مانده بی‌مالک می‌شود. اگر پاکسازی قبلی ناقص بماند، استفادهٔ مجدد از آیدی برای حفظ حریم خصوصی **مسدود** می‌شود. کاربرانِ مجاز آیدی/نمایه و همهٔ کاربران رمز خود را تغییر می‌دهند.
- **گفتگوها:** پیام خصوصی، پیام‌های ذخیره‌شدهٔ مخصوص خودت، گروه/کانال، متن/عکس/ویدیو/ویس/صوت/هر فایل، پاسخ، ویرایش، فوروارد، واکنش، سنجاق، جستجو، نمایش خوانده‌شدن، بایگانی و بی‌صدا. گروه/کانال را از منو بساز؛ خصوصی فقط با **لینک دعوت معتبر یا افزودن مدیر** و عمومی با **آیدی دقیق یا جستجوی نام گروه/کانال** قابل پیوستن است؛ نام و اعضای گروه‌های خصوصی در جستجوی عمومی فاش نمی‌شود. در اطلاعات گروه می‌توانی لینک را کپی کنی، برای خصوصی لینک قبلی را باطل کنی، عضو را با آیدی دقیق اضافه/حذف کنی یا (اگر مدیر کل نیستی) گروه را ترک کنی. کانال را فقط مدیران مجاز می‌نویسند. کانال موجودِ **«اطلاعیه‌های عمومی سیستم»** برای همهٔ حساب‌های قدیمی و تازه الزامی، فقط قابل‌نوشتن توسط مدیر سامانه و غیرقابل خروج یا حذف است. نخستین مدیر ساخته‌شده هنگام نصب هم مخاطب خصوصیِ ثابت تمام کاربران است (نمی‌توان حذف، مسدود یا تغییر آیدی‌اش داد). **لینک خصوصی را فقط به آدم‌های مورد اعتماد بده**؛ دارندهٔ لینک معتبر می‌تواند عضو شود. توکن لینک در بخش `#` نشانی است و در درخواست اولیهٔ وب‌سرور فرستاده نمی‌شود، ولی ممکن است در تاریخچه/کلیپ‌بورد/اشتراک‌گذاری دستگاه بماند.
- **استیکر و شکل‌وشمایل:** از عکس خودت یک استیکر **ثابت** با پس‌زمینهٔ شفافِ ۵۱۲×۵۱۲ در خود مرورگر بساز (WebP، حداکثر ۵۱۲ KiB)، به مجموعهٔ شخصی اضافه کن و بفرست. GIF ورودی ثابت می‌شود؛ استیکر متحرک ادعا نشده. ۱۱ پوستهٔ روشن/تاریک، آسمانی/اقیانوسی و ملایمِ رز/یاسی/هلویی/آلوئی داریم؛ پیش‌فرض روشن تلگرام‌گونه است. ۱۰ قلم **محلی و با مجوز آزاد** (وزیرمتن، استعداد، ساحل، شبنم، صمیم، پرستو، گندم، میخک، نوتو سنس عربی و نوتو نسخ عربی) را در تنظیمات انتخاب کن؛ ایران‌سنس به دلیل مجوز اختصاصی همراه نیست. اندازهٔ متن واقعی پیام‌ها هم کوچک/استاندارد/بزرگ می‌شود. پوسته، قلم، اندازهٔ پیام و گزینهٔ «Enter برای ارسال/Enter برای خط بعد» برای هر حساب در همان مرورگر جدا می‌مانند. حرکت‌های کوتاه رابط با تنظیم «کاهش حرکت» سیستم خاموش می‌شوند.
- **فضای شخصی:** Saved Messages، پوشه/فایل/یادداشت رمز‌شده و سهمیهٔ اختصاصی. عکس، ویدیو و صوت با درخواست‌های Range پخش می‌شوند؛ آپلود حجیم به قطعه‌های کوچک تقسیم می‌شود. اگر **۸۰٪ از سهمیه** پر شود، هشدار مشخص بالای برنامه می‌آید و آپلود/ارسال رسانهٔ جدید (شامل ویس و استیکر) متوقف می‌شود؛ **متن همچنان کار می‌کند**. فایلی که تازه از زیر ۸۰٪ عبور کرده، آپلود و ارسال اولش را تکمیل می‌کند؛ ارسال‌های بعدی تا آزادسازی فضا بسته می‌شوند. از منو یا هشدار، «رسانه‌های من» را باز کن؛ فایل‌های آپلودشدهٔ خودت را در همهٔ گفتگوها/Drive/استیکرها می‌بینی و تا ۲۰ مورد در هر نوبت انتخاب می‌کنی.
- **حذف بدون وعدهٔ گمراه‌کننده:** «فقط برای من» نمای تو و ارجاع‌های شخصی تو را پاک می‌کند؛ کپی طرف مقابل می‌ماند و ممکن است **هیچ حجمی از سهمیه آزاد نشود**. «برای همه» با رمز فعلی، پیام‌های رسانه‌ای **ارسال‌شدهٔ خودت** را در همهٔ گفتگوهای قابل‌دسترسی پاک می‌کند؛ فورواردی که دیگری فرستاده یا ارجاعِ باقی‌ماندهٔ دیگران را بی‌اجازه حذف نمی‌کند. حجم فقط وقتی آزاد می‌شود که آخرین ارجاع فایل حذف شده باشد. فایل دانلودشدهٔ گیرنده و بکاپ قبلی پاک نمی‌شود. برای پاکسازی کامل دادهٔ **حساب خودت** از تنظیمات و رمز فعلی/عبارت `RESET` استفاده کن؛ نسخهٔ مشترک دیگران باقی می‌ماند و آیدی و رمز تو حفظ می‌شود.
- **ویدیوی بزرگ:** قبل از ارسال هشدار/انتخاب داری: کم‌حجم‌سازی **واقعی روی دستگاه و با اجازهٔ تو** یا ارسال اصل. پردازش Canvas + MediaRecorder + WebAudio به مرورگر/کدک/مدت ویدیو بستگی دارد؛ اگر صدا حفظ نشود یا خروجی کوچک‌تر نباشد، برنامه از تو می‌خواهد اصل را بفرستی. هیچ FFmpeg یا سرویس خارجی برای چت لازم نیست؛ ارسال هر نوع فایل اصل هم آزاد است، مگر محدودیت سهمیه.

## امکانات نسخهٔ ۴.۱ که در ۴.۲ هم حفظ شده‌اند

- وضعیت آنلاین به **صفحه‌های باز** متصل است: بستن تب/صفحه یک درخواست خروج می‌فرستد و پس از بسته‌شدن آخرین تب، آنلاین خاموش می‌شود؛ اگر درخواست بسته‌شدن به سرور نرسد، heartbeat حداکثر حدود **۳۵ ثانیه** بعد منقضی می‌شود. صفحه‌ای که فقط به پس‌زمینه رفته، ممکن است همچنان آنلاین باشد.
- تیک «خوانده شد» با ورود یا همگام‌سازی خودکار زده نمی‌شود؛ بعد از **بازشدن و نمایش گفتگو در صفحهٔ قابل مشاهده** تأیید می‌شود. پیام کانال با **نام کانال** و پیام گروه با **نام فرستندهٔ واقعی** نمایش داده می‌شود.
- بعد از اولین ورود در همان مرورگر، نصب PWA پیشنهاد می‌شود؛ حتی پس از رد، دکمهٔ نصب بالای برنامه می‌ماند. نصب به **HTTPS** و پشتیبانی مرورگر بستگی دارد؛ هستهٔ چت حتی بدون نصب کار می‌کند. صفحهٔ بارگذاری از چشمک‌زدن فرم ورود هنگام تازه‌سازی نشست معتبر جلوگیری می‌کند.
- منوی پیوست، **عکس با دوربین گوشی** و **اشتراک موقعیت با اجازهٔ مرورگر + تأیید نهایی شما** را دارد؛ موقعیت به‌صورت پیوند نقشه در همان گفتگو فرستاده می‌شود و در دستگاه/مرورگر فاقد مجوز، ارسال نمی‌شود. در مرورگر بدون دوربین گوشی، انتخاب عکس جایگزین است. در گفتگوی خصوصی می‌توانی کاربر را مسدود/رفع مسدودی کنی؛ دو طرف تا رفع مسدودی حق پیام یا واکنش تازه ندارند، اما تاریخچهٔ قبلی حفظ می‌شود.
- شکلک/استیکر بین دو زبانه بدون بسته‌شدن ناخواسته جابه‌جا می‌شوند. آیکن‌ها و فونت‌ها همراه خود بسته‌اند و اتصال به CDN برای رابط لازم نیست.

## آمار استفادهٔ حساب‌ها برای مدیر اصلی (نسخهٔ ۴.۲)

**مسیر:** با حسابی که در `setup.php` به‌عنوان **اولین مدیر** ساخته‌ای وارد شو ← منو ← «پنل مدیریت کل سامانه» ← **«آمار استفادهٔ حساب‌ها»**. این زبانه برای مدیرهای بعدی و کاربران عادی پنهان است و درخواست مستقیم API آن‌ها هم با 403 رد می‌شود. آمارِ همهٔ حساب‌ها، شامل حساب مسدود یا مدیران دیگر، دیده می‌شود؛ با کادر نام/آیدی جستجو کن یا «هرگز وارد نشده»، «۷ روز بی‌حضور»، «۳۰ روز بی‌حضور» و «اکنون آنلاین» را فیلتر کن. دکمهٔ **به‌روزرسانی وضعیت**، زمانِ واقعیِ آخرین بارگیری گزارش را نشان می‌دهد.

- **تاریخ و ساعت ساخت** هنگام نصب مدیر اول، ساخت کاربر در پنل یا ایجاد از ویرایشگر خام JSON در `data/user_activity.json` مخصوص همان هاست ثبت می‌شود. تغییر نام آیدی این تاریخ را نگه می‌دارد؛ حذف امن و ساخت دوبارهٔ یک آیدی، تاریخ قبلی را **به صاحب جدید منتقل نمی‌کند**. برای حساب‌های ساخته‌شده **پیش از ارتقا** که تاریخ ثبت نشده، به‌صراحت «نامشخص (حساب قدیمی)» می‌بینی؛ از ترتیب `users.json` یا تاریخ فایل، تاریخ جعلی تولید نمی‌کنیم.
- **آخرین ورود موفق** فقط پس از ورود واقعی با رمز ثبت می‌شود؛ صرف ساخت حساب، ویرایش/ریست رمز یا فعال‌کردن آن «استفاده» شمرده نمی‌شود. برای حساب قدیمی بدون ثبت ورود، اگر شواهد قبلی موجود نباشد، عبارت «ثبت نشده در این نسخه» می‌آید، نه ادعای «هرگز وارد نشده».
- **آخرین حضور/فعالیت ثبت‌شده** از heartbeat تب‌های باز و زمان بستن تب (`data/presence.json`) به‌دست می‌آید؛ اگر حضور ذخیره نشده ولی ورود ثبت شده باشد، زمان ورود نزدیک‌ترین شاهدِ قطعی است. تاریخ‌ها با **تقویم شمسی و ساعت ایران** در رابط نشان داده می‌شوند و «۷/۳۰ روز» یعنی ۷/۳۰ بازهٔ کامل ۲۴ساعته از آخرین حضورِ ثبت‌شده، نه صرف عوض‌شدن تاریخ روی تقویم.
- **«هرگز وارد نشده» فقط برای حساب دارای تاریخ ساختِ ثبت‌شده و بدون هیچ ورود/حضور ثبت‌شده** نمایش داده می‌شود. برای حساب قدیمی با تاریخچهٔ نامعلوم، برچسب «آمار گذشته نامشخص» است؛ چنین حسابی را صرفاً بر اساس این برچسب بی‌مصرف فرض نکن. فیلترهای ۷/۳۰ روز، حساب‌های قبلاً استفاده‌شده را نشان می‌دهند و حساب هرگز واردنشده را جدا حساب می‌کنند.

**محدودیت مهم:** «آنلاین» یعنی حداقل یک تب تا حدود ۳۵ ثانیهٔ اخیر حضور معتبر داشته، حتی اگر در پس‌زمینه باز مانده باشد؛ دلیل قطعیِ خواندن، پیام‌فرستادن یا استفادهٔ مفید نیست. اگر درخواست بستن صفحه به هاست نرسد، وضعیت پس از انقضای heartbeat خاموش می‌شود. زمان‌ها **فرادادهٔ رمز‌نشده** در `data/` محافظت‌شده‌اند: `user_activity.json` و `presence.json` را همراه **کل `data/`** خصوصی بکاپ بگیر و دسترسی مستقیم وب به آن‌ها را قبل از راه‌اندازی آزمایش کن. ZIP نصب تازه این داده‌ها را ندارد؛ در ارتقا آن را روی دادهٔ فعال Extract نکن.

## ابزار اختیاری کانال عمومی تلگرام (دقیقاً چه چیزی می‌دهد؟)

در چت «دستیار/خدمات» آیدی کانال عمومی را در کادر بزن یا `/telegram @channel_id` بفرست. برنامه فقط صفحهٔ عمومی `https://t.me/s/CHANNEL_ID` را **بدون ورود، شماره یا Bot API** می‌خواند: تا **۲۰ پستِ واقعاً قابل مشاهدهٔ همان پیش‌نمایش** با متن کوتاه، تاریخ، لینک منبع و نوع رسانه به‌صورت پیام‌های جدا می‌آید. اگر پیش‌نمایش نشانی مستقیم CDN عکس/ویدیو/صوت/فایل را بدهد، مرورگر تا ۲۰ تلاشِ جداگانه برای دریافتِ **نسخهٔ قابل‌دریافت** می‌کند؛ محدودیت هر عکس ۲ MiB، ویدیو ۶ MiB، صوت ۳ MiB و فایل ۵ MiB است. فایل پذیرفته‌شده داخل فضای رمز‌شدهٔ خودت ذخیره و به چت خدمات پیوست می‌شود و در سهمیه‌ات حساب می‌شود. برای تکمیل کار صفحه را باز نگه دار. اگر دانلود/فرمت/سهمیه/اتصال جواب ندهد، خطا با پیوند همان پست **در چت گزارش** می‌شود؛ اگر اصلاً نشانی مستقیم در HTML نباشد، متن پست نوع رسانه و «فایل اصلی در پیش‌نمایش موجود نیست» را روشن می‌نویسد.

**واقع‌بینانه:** تلگرام ممکن است بعضی پست‌ها، اسناد، نسخهٔ اصلی، آلبوم کامل یا فایل بزرگ را اصلاً در پیش‌نمایش ندهد؛ ساختار HTML/لینک‌های CDN می‌توانند عوض شوند. قولِ دقیقاً ۲۰ پست، بازیابی پست خصوصی یا برابری بایت/کیفیت با تلگرام نداریم. اگر هاست به `t.me`/CDN دسترسی نداشته باشد خطای دریافت می‌بینی. جواب موفق ۹۰ ثانیه و نشانی پیوست برای تکمیل کار تا ۱۰ دقیقه در `data/` محافظت‌شده کش می‌شود. AI/ویکی‌پدیا/جستجوی وب هم اختیاری و تحت کنترل مدیرند؛ جواب ویکی‌پدیا **مقدمهٔ مقاله** است و همیشه پیوند متن کامل دارد، و هر بریدهٔ طولانیِ وب/پاسخ محدودشدهٔ AI صریحاً ناتمام بودنش را نشان می‌دهد. با `/rates` می‌توان **دلار آزاد، گرم طلای ۱۸ عیار و سکهٔ امامی** را از صفحه‌های عمومی TGJU بدون کلید API خواند؛ نتیجه منبع، واحد **ریال/تومان**، زمان ثبت در تابلو و آخرین دریافت را نشان می‌دهد. اگر سایت یا ساختار صفحه در دسترس نباشد، پاسخ «قدیمی/ناموجود» می‌آید و **هیچ عدد نمونه‌ای به جای نرخ زنده نمایش داده نمی‌شود**. ساعتِ روی تابلو به‌تنهایی تاریخ معامله را ثابت نمی‌کند؛ این ابزار جای منبع مالی معتبر یا اعلام نرخ لحظه‌ای تضمینی نیست. دادهٔ محرمانه را بی‌احتیاط به سرویس خارجی نفرست.

## ذخیره‌سازی و امنیت، بی‌اغراق

هر گفتگو خودش به `data/chats/CHAT_ID/part_0001.json`، `part_0002.json` و ... تقسیم می‌شود؛ قفل فایل (`flock`) و تعویض اتمی JSON برای نوشتن استفاده شده است. جستجو/تاریخچه صفحه‌بندی دارد، اما هاست اشتراکی **ظرفیت نامحدود ندارد**: فضای دیسک، بکاپ، محدودیت پردازش PHP و تعداد قطعات را زیر نظر بگیر.

متن پیام، خلاصهٔ نمای گفتگو و یادداشت‌ها با **AES-256-GCM** و فایل تازهٔ کامل‌شده با بلوک‌های احرازاصالت‌شدهٔ ۱ MiB و کلید وابسته به شناسهٔ فایل رمز می‌شوند؛ رمز حساب‌های تازه Bcrypt است. **نام/نوع/حجم فایل، اعضای گروه، زمان/ردپاها و تاریخ‌های حساب/حضور در `data/user_activity.json` و `data/presence.json`، کش پیش‌نمایش عمومی و قطعات موقتِ آپلود رمز نشده‌اند**؛ قطعات موقت فقط در پوشهٔ محافظت‌شده‌اند و ممکن است تا پاکسازی بعدی بمانند. کلید سرور در `data/.master_secret.php` ساخته می‌شود. **E2EE نیست:** خود PHP برای نمایش محتوا را باز می‌کند؛ مدیر هاست یا کسی که به کلید و داده با هم دسترسی پیدا کند می‌تواند محتوا را بخواند. HTTPS برای مسیر شبکه ضروری است؛ بکاپ‌های قبلی/گیرنده‌ها از حذف پیام عقب‌گرد نمی‌کنند. برای شرح دقیق‌تر [`SECURITY.md`](SECURITY.md) را بخوان.

```bash
git init -b main
git add .
```

اگر مخزن محلی قبلاً `origin` دارد، پیش از `git remote add` خروجی `git remote -v` را ببین و دستور را دوباره اجرا نکن. برای احراز هویت از روش امن GitHub CLI، مدیر اعتبارنامه یا SSH استفاده کن؛ **رمز/PAT را در فایل پروژه، URL یا چت نگذار**. فقط **بعد از اینکه کد واقعاً در GitHub قابل مشاهده شد**، در پنل مدیر «تنظیمات عمومی → آدرس مخزن GitHub» نشانی واقعی را ذخیره کن؛ لینک صفحهٔ ورود تا زمان ذخیره‌کردن نشانی، پنهان است. ZIPهای اینجا commit/push یا Release واقعی ایجاد نمی‌کنند.
